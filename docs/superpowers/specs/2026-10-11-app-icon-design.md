# 应用图标设计（1.16）

> 这一轮换掉了从 1.0 就在用的图标：天蓝色细线地球 + 深蓝方块。
> 真机反馈原话是「应用图标也需要更改，联网搜索一个好看的」。

配套原型：[`prototype/icon.html`](../../../prototype/icon.html)（纯静态，打开即可，按 `1`–`4` 切换方案）。

**这份文档记的是最终方案，也记了被否掉的七版。** 第一版「重铸地球」发出去之后被退回来
一次——原话是「图标还是丑，你来设计吧」，所以这里把每一版为什么不行写清楚，
免得下次又走一遍。

---

## 1. 换掉它的理由

旧图标有两个硬伤，都是「在 1024px 上好看、在桌面上不好看」那一类：

1. **细线撑不住小尺寸。** 旧前景是 Phosphor Regular 的描边地球，换算到 108dp 画布上
   线宽约 4dp。缩到 48px 时线只剩不到 2 个像素，真机上看到的就是「一个浅色的圈」。
   自适应图标的设计规范把这条写得很直白：细线在小尺寸下会消失，该换成粗壮的实心形。
2. **纯色底没有光。** `#0F172A` 平铺一块，桌面上是一块「死」的方块，没有方向感，
   也没有体积感。

还有一条不是硬伤但值得说：**浏览器图标几乎清一色蓝白**（Chrome、Edge、QQ 浏览器、
小米浏览器、Via、Alook），旧图标正好也在这个拥挤区里。

---

## 2. 参考了什么

联网查了主流浏览器与国产浏览器的现行图标做法，以及自适应图标的官方规范。

| 参考 | 它的做法 | 这里借鉴了什么 |
|---|---|---|
| Chrome | 四色风车，2022 版去掉阴影但**加了很轻的渐变**，专门为了消掉红绿之间的色彩振动 | 渐变是为了「小尺寸下不糊」，不是为了好看 |
| Edge | 波浪形的 e，用**精确的圆形几何**搭出来，蓝→青渐变是为了在深浅两种底上都能读 | 几何要简单到能一眼认出 |
| Firefox | 狐狸抱地球，靠**大块简化形状**而不是细节 | 一个主体，不堆装饰 |
| Brave | 几何狮子，橙红配石墨，**刻意不跟蓝色大流** | 绿色在这个品类里是空位 |
| Arc | 一条抽象的弧，紫→珊瑚渐变 | 抽象也能成立，但要有体积 |
| 夸克 / Via / Alook | 极简：白底 + 一个高对比的抽象记号 | 留白与对比比细节重要 |
| 官方自适应图标规范 | 108dp 画布、中央 66dp 安全区、外圈 18dp 留给遮罩与视差；遮罩由各家桌面决定（国内桌面基本是圆形）；建议提供单色层 | 所有尺寸都按安全区算 |

被引用到的经验条目：

- 细线在 1024px 上好看，缩到 48px 就没了；应该在 **29px / 60px** 这种尺寸上验收，
  而不是在 1024px 上。
- 「一个主体 + 最多一个点缀」；三个以上元素在小尺寸下会变成噪点。
- 渐变与轻阴影比纯平色更容易在小尺寸下立住；但别做成重拟物，容易过时。

## 3. 被否掉的七版

每一版都按 128 / 96 / 64 / 48 / 32px 五档渲染出来看过，也叠了圆形遮罩和 33dp 安全圈。
记在这里的是**它读起来像什么**——判断标准就是这一条：图标读成别的什么东西，就是不行。

| # | 形状 | 否决理由 |
|---|---|---|
| 1 | 对称拱 + 地平线 | 读成门框 / 墓碑 |
| 2 | 竖直帘幕（等宽竖条） | 读成条形码 |
| 3 | 单条斜扫（等宽） | 读成 Nike 勾 |
| 4 | 旋涡 | 读成数字 6 |
| 5 | 对称拱，两端收尖 | **读成彩虹**——这一版一度上线，被退回来 |
| 6 | 不对称斜扫，右端带钩 | 读成鱼鳍 / 海浪 |
| 7 | 帘幕层叠（两条交叉窄带） | 读成两片交叉的叶子 |
| 8 | **不对称弧 + 外圈晕 + 伴带 + 星** | 采用 |

第 5 版是关键的一次教训：**对称的拱 = 彩虹**。这个问题不是靠调宽度、调弧度能解决的，
它来自对称本身，所以第 8 版的第一件事就是把中心线做成不对称的。

第 6、7 版则暴露了另一件事：**只改轮廓永远会在「像彩虹」和「像别的什么东西」之间来回跳**。
真正的差别不在轮廓上——**彩虹是一条边缘锋利的色带，极光是一团散开的光。**
所以第 8 版加的不是新形状，是一层光。

## 4. 采用的方案：一道极光

### 4.1 四层

| 层 | 文件 | 内容 | 不透明度 |
|---|---|---|---|
| 底 | `drawable/ic_launcher_background.xml` | 深青夜空，径向渐变，光源偏低偏中 | — |
| 前景 · 晕 | `drawable/ic_launcher_foreground.xml` | 同轴、极宽的带，当光晕用 | 0.13 |
| 前景 · 伴带 | 同上 | 细带，在主弧上方偏左 | 0.40 |
| 前景 · 主弧 | 同上 | 青 → 薄荷 → 近白的三段渐变 | 1.0 |
| 前景 · 星 | 同上 | 凹边四角星 + 一圈淡光晕 | 1.0 / 0.16 |
| 单色 | `drawable/ic_launcher_monochrome.xml` | 伴带 + 主弧 + 星（**不画晕**） | 同前景 |

### 4.2 几何

画布 108×108，中心 (54,54)。所有曲线都是三次贝塞尔，按 110 个采样点近似成折线，
再沿法线向两侧各偏移半个带宽，拼成一条闭合路径——带宽是沿曲线变化的，
所以不能用 `stroke-width`。

**主弧中心线**：`(26,78) → (32,20) → (58,13) → (80,56)`

左腿从画布左下起、压得低而长，峰落在 x≈55（中心偏右），右腿收到 (80,56)。
**这就是「不对称」的全部内容**：把峰往右挪、让两条腿不一样长，拱就不再是彩虹。

**带宽函数**（`t` 是沿曲线的参数，`d = |t − centre| / 0.5`）：

```
w(t) = base + peak · max(0, 1 − d^1.6)^0.7
```

两端收到接近零（`d → 1` 时 `w → base`），中间最厚。三层的参数：

| 层 | base | peak | centre | 最厚处宽度 |
|---|---|---|---|---|
| 晕 | 0.5 | 26 | 0.46 | 26.5dp |
| 主弧 | 3.0 | 13 | 0.46 | 16dp |
| 伴带 | 1.0 | 5.5 | 0.44 | 6.5dp |

**伴带中心线**：`(30,70) → (35,23) → (60,15) → (79,58)`——不是主弧的简单平移，
整体在主弧上方偏左一点，两条弧的间距沿程是变的。

**主弧渐变**：线性，从 (28,72) 到 (81,22)，`#E63FC7F5` → `#FF7FF3D0` → `#FFF7FFFC`。
左下偏青、右上近白，像是同一道光在明暗里走了一遍。

**星**：中心 (80,32)，半径 4.4dp，凹边（控制点取半径的 16%），外面套一个半径 9.68dp、
16% 不透明的白圆当光晕。

**尺寸**：最远处离中心 **39.20dp**，整组用 `group` 等比缩放 **0.8163** 后落在 **32.00dp**，
在 66dp 安全区（半径 33dp）以内。缩放系数是脚本算出来的，不是手调的。

### 4.3 为什么这么定

- **不对称。** 见 §3 第 5 版。对称的拱就是彩虹，没有别的可能。
- **晕是这一版的核心，不是装饰。** VectorDrawable 没有模糊，就用一层同轴、峰宽 26dp、
  透明度 13% 的带当晕。它让主体读起来是「光」而不是「色块」——这正是极光和彩虹的分界。
- **晕不影响清晰度。** 晕只有 13% 不透明，轮廓仍然由主弧决定，所以大尺寸下不糊；
  小尺寸下它反而把主弧的边「托」出来，比单画一条硬边更清楚。
- **绿色而不是蓝色。** 品类里的空位，而且深青 `#155A45` / 薄荷 `#7FF3D0` 与 1.16
  浅色主题的松绿 `#0F5C4A` 是同一族，图标与应用内部是同一套颜色。
- **主弧够粗。** 最厚处 16dp，缩放后 13dp；在 48px 下约 6 个像素（旧地球的线不到 2 个）。
- **单色层不画晕。** 主题图标按 alpha 取形状，晕画上去只会把主体撑胖一圈。
  伴带保留 40% 透明度，主题图标上也就有了「一道亮一道淡」的层次。

## 5. 对比度与可用性

| 项 | 值 |
|---|---|
| 主弧最亮处 / 底色最深处 | `#F7FFFC` / `#04120F` |
| 底色最亮处 / 深色壁纸 | `#155A45` 与深色壁纸仍有明度差，不会融进背景 |
| 最小可辨尺寸 | 48px 时仍是一条清楚的弧；32px 时收成一个亮弧，没有塌成一团 |
| 遮罩 | 圆形 / 圆角方形 / 方形都验过（见原型），无裁切；安全圈余量 1dp |

## 6. 没做的事

- **没有生成位图 mipmap。** minSdk 26，`mipmap-anydpi-v26` 恒生效，不需要再补 PNG。
- **没有做启动页（splash）图标。** Android 12+ 的启动画面默认取应用图标，够用；
  单独做一套是另一件事。
- **没在真机桌面上验收。** 尺寸结论来自 Chrome 渲染与几何实算；模拟器上装过、
  应用信息页的图标是对的（`.shots/icon-aurora-info.png`），但真机桌面
  （iQOO Z11X / OriginOS）的观感还要再看一眼。
- **备选方案只在原型里留档**，没有进代码：`prototype/icon.html` 的 B/C/D 三套
  （重铸地球 / 北极星 / 门径）随时可以换上去。
- **几何是脚本生成的，不是手抄的。** `.tmp/icon/gen_final.py` 出三个 VectorDrawable，
  `.tmp/icon/gen_proto.py` 出原型页，两边读的是同一组坐标常数。
  脚本在 `.tmp/` 下（已 gitignore），要改形状得先把它捞出来。
