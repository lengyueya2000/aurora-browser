# Aurora Browser（极光浏览器）设计规格

- **文档版本**：v1.0
- **日期**：2026-10-11
- **状态**：待评审
- **产品代号**：Aurora（工作名，可替换）
- **平台**：Android 8.0+（API 26+），targetSdk 35
- **技术栈**：Kotlin + Jetpack Compose（Material 3）+ WebView / GeckoView
- **设计系统来源**：`ui-ux-pro-max` 本地数据集（style = Dark Mode (OLED)；color = Developer Tool / IDE 深色调色板；typography = Minimal Swiss / Inter + JetBrains Mono）

---

## 1. 产品定位

### 1.1 一句话定位

**Aurora 是一款「全能功能型」安卓浏览器：在单手可及的界面上，把标签管理、拦截、阅读、下载、书签、扩展这些能力收进一个克制的深色界面里。**

### 1.2 目标用户

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 重度多标签用户 | 通勤、查资料、比价 | 几十个标签不乱、能分组、能恢复 |
| 隐私敏感用户 | 日常浏览 | 看得到拦截了什么、能控权限 |
| 内容阅读者 | 长文、新闻、小说 | 阅读模式、字号调节、夜间护眼 |
| 资源下载用户 | 视频/文档/安装包 | 后台下载、断点续传、好找 |

### 1.3 设计原则

1. **单手可达优先**：所有高频操作落在屏幕底部 1/3。顶部只放「看」的信息（地址、站点身份），底部放「做」的动作。
2. **功能全，界面静**：能力很多，但默认只呈现一个地址栏 + 一条底部工具栏；其余能力收进菜单面板与二级页面。
3. **深色是第一公民**：以 OLED 深色为默认主题，浅色是派生主题，两套都由语义 token 驱动。
4. **状态永远可见**：加载进度、拦截计数、无痕标识、同步状态都在界面上有明确位置，不做「静默魔法」。
5. **不做装饰性动画**：每屏最多 1–2 处动效，全部尊重 `prefers-reduced-motion` / 系统「移除动画」。

### 1.4 非目标（本期不做）

- 桌面端 / iOS 端
- 自研渲染引擎
- 内置 AI 助手（预留在菜单占位，不在本期范围）
- 账号体系后端实现（只定义 UI 与状态位）

### 2.2 字体

- **UI 字体**：`Inter`（Minimal Swiss，单一字族靠字重分层）→ Android 上 fallback 到 `Roboto` / 系统字体，中文回落到 `Noto Sans SC`。
- **等宽字体**：`JetBrains Mono` —— **仅用于地址栏 URL、域名、代码片段、拦截计数**等技术性字符串。

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--text-display` | 28 / 34 sp | 700 | 无痕模式标题、空状态大标题 |
| `--text-title` | 20 / 26 sp | 600 | 页面标题、面板标题 |
| `--text-heading` | 17 / 24 sp | 600 | 卡片标题、设置分组标题 |
| `--text-body` | 15 / 22 sp | 400 | 正文、列表主文案 |
| `--text-label` | 13 / 18 sp | 500 | 按钮、标签、辅助信息 |
| `--text-caption` | 11 / 15 sp | 500 | 角标、时间戳 |
| `--text-mono` | 14 / 20 sp | 500 | URL / 域名 / 计数 |

> 支持系统字体缩放：正文在 200% 缩放下不得截断或重叠；容器用 `sp`，间距用 `dp`。

### 2.3 间距 / 圆角 / 高度

- **间距节奏（4/8dp）**：`--space-1:4` `--space-2:8` `--space-3:12` `--space-4:16` `--space-5:24` `--space-6:32` `--space-7:48`
- **圆角**：`--radius-xs:6` `--radius-sm:10`（按钮/输入）`--radius-md:14`（卡片）`--radius-lg:20`（面板/底部工具栏）`--radius-xl:28` `--radius-full:999`（胶囊）
- **最小触摸目标**：**48×48dp**（Android），图标视觉尺寸 24dp，不足时用透明内边距外扩命中区。
- **相邻触摸目标间距**：≥ 8dp。
- **安全区**：底部工具栏与顶部地址栏必须应用 `WindowInsets`（状态栏 + 手势导航条），任何可点内容不得压在手势条 / 挖孔下。

### 2.4 高度与阴影（深色）

深色下靠「亮一档的表面 + 细描边」表达层级，阴影为辅。

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-1` | `0 1px 2px rgba(0,0,0,.40)` | 卡片 |
| `--shadow-2` | `0 4px 12px rgba(0,0,0,.45)` | 悬浮工具栏 |
| `--shadow-3` | `0 12px 32px rgba(0,0,0,.50)` | 底部面板 / 对话框 |

### 2.5 动效

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 120 ms | 按下反馈、图标切换 |
| `--dur-base` | 200 ms | 面板进出、标签切换 |
| `--dur-slow` | 320 ms | 页面转场 |
| `--ease-standard` | `cubic-bezier(.2,0,0,1)` | 通用 |
| `--ease-decelerate` | `cubic-bezier(0,0,0,1)` | 入场 |
| `--ease-accelerate` | `cubic-bezier(.3,0,1,1)` | 退场 |

规则：入场用 decelerate 且比退场慢；**退场时长 ≤ 入场**；按压反馈在 80–150ms 内出现；按压态只改颜色/透明度/高度，**不得改变布局尺寸**（避免抖动）。系统开启「移除动画」时全部降级为即时切换。

### 2.6 图标

- 库：**Phosphor Icons（Regular，Outline 风格）**，本规格原型已内联真实 Phosphor path。
- 同一层级只用一种风格（线性 or 填充），描边粗细统一。
- 尺寸 token：`icon-sm 16dp` / `icon-md 20dp` / `icon-lg 24dp` / `icon-xl 32dp`。
- 装饰性图标（旁边有可见文字）对无障碍树隐藏；独立图标按钮必须带可访问名称并暴露选中/展开状态。
- **禁止用 emoji 充当结构图标。**

## 4. 导航模型与手势

**底部工具栏（5 槽，拇指区）**：`返回` · `前进` · `主页/新标签` · `标签（带计数角标）` · `菜单`

**顶部地址栏**：左侧站点身份图标（锁 / 盾 / 警告）+ 域名（mono 字体）+ 右侧刷新/停止。

**手势**

| 手势 | 行为 |
|---|---|
| 屏幕左/右边缘向内滑 | 返回 / 前进 |
| 底部工具栏下拉 | 展开标签管理 |
| 地址栏上滑 | 进入 omnibox 聚焦态 |
| 地址栏左右滑 | 切换相邻标签 |
| 长按标签卡片 | 多选：关闭/移动/加入组 |
| 双指下拉（网页区） | 触发刷新 |

**返回键行为**：先关面板 → 再退 omnibox 聚焦 → 再网页后退 → 最后双击退出（首次按提示「再按一次退出」）。**不得在第一次按返回键就直接退出应用。**

## 5. 页面规格

> 每页给出：目的 / 结构 / 关键组件 / 状态。原型对应 `prototype/index.html` 中的编号屏幕。

### 5.1 主页 / 新标签页（01）

- **目的**：启动后的落脚点，3 秒内可发起搜索或进入常用站点。
- **结构（上→下）**：状态栏 → 地址栏（胶囊，占位「搜索或输入网址」）→ 快捷入口 4×2 网格（带「+」）→ 底部工具栏。
- **组件**：`OmniboxBar`、`ShortcutTile`、`BottomToolbar`。
- **状态**：空（无快捷入口 → 显示引导「添加常用网站」）、无网络（顶部细条「当前离线，显示缓存内容」）。

### 5.2 地址栏聚焦态 / Omnibox（02）

- **目的**：输入与快捷动作。
- **结构**：地址栏展开为输入框（自动聚焦、键盘弹出）→ 建议列表（搜索建议 / 历史 / 书签，行首用类型图标区分）→ 底部快捷动作行（扫码、语音、粘贴并前往、无痕）。
- **组件**：`OmniboxInput`、`SuggestionRow`、`QuickActionRow`。
- **状态**：无输入（显示剪贴板建议 + 热门站点）、有输入（建议实时刷新）、空结果。

### 5.3 网页浏览（03）

- **目的**：内容主体。
- **结构**：顶部地址栏（站点盾牌 + 域名 + 刷新）→ 顶部 2dp 加载进度条 → 内容区 → 底部悬浮玻璃工具栏（返回/前进/主页/标签/菜单）。
- **组件**：`SiteIdentity`、`ProgressBar`、`FloatingToolbar`。
- **状态**：加载中（进度条 + 停止按钮）、加载完成（刷新按钮）、证书警告（地址栏变警告色 + 页面拦截页）、离线（错误页）。
- **媒体**：HTML5 视频全屏由应用接管（`WebChromeClient` 的全屏回调 → 铺满窗口 + 隐藏系统栏 + 返回键先退全屏）；页面内的视频源可从菜单「下载视频」入队下载，或「投屏」交给系统投屏 / 能播 `video` 的应用。

### 5.4 标签管理（04 / 05）

- **目的**：在几十个标签中快速定位与清理。
- **结构**：顶部「标签数 + 网格/列表切换 + 新建 + 无痕」→ 标签卡片（favicon + 标题 + 关闭）→ 网格（2 列）或列表（分组：标签组折叠、普通标签、最近关闭）。
- **组件**：`TabCard`、`TabGroupHeader`、`ViewToggle`。
- **状态**：空（引导开新标签）、多选（顶部工具条：关闭/加入组/移动）、无痕标签（深黑卡片 + 遮罩图标）。

### 5.5 主菜单面板（06）

- **目的**：收纳低频但重要的功能。
- **结构**：底部抽屉（圆角上沿 + 拖拽把手）→ 常用动作 4×2 网格（书签、历史、下载、阅读模式、分享、无痕、隐私、设置）→「媒体」组（下载视频、投屏）→「标签页」组（新建、刷新、关闭全部、标签数）。
- **组件**：`BottomSheet`、`ActionGridTile`、`SettingRow`。
- **状态**：正常 / 无痕模式下（部分项禁用并置灰）/ 媒体面板（视频源列表：流式 `blob:` 地址标为「不支持」；投屏分「屏幕镜像」与「投屏播放视频」两条路径）。

### 5.6 隐私与安全面板（07）

- **目的**：让隐私「可看见、可控制」。
- **结构**：顶部拦截计数大数字（mono）+ 盾牌图标 → HTTPS 状态行（绿）→ 追踪器分类列表（广告/分析/社交/指纹，各带数量）→ 站点权限开关行（相机、麦克风、定位、通知、剪贴板）。
- **组件**：`BlockCounter`、`TrackerCategoryRow`、`PermissionRow`。
- **状态**：零拦截（「本页没有发现追踪器」）、已加白名单。

### 5.7 阅读模式（08）

- **目的**：去噪长文阅读。
- **结构**：顶部标题 + 来源域名 → 正文（优化行宽、段距）→ 底部控制条（字号 A- A+、字体、主题：深/浅/护眼、朗读）。
- **组件**：`ReaderControlBar`、`SegmentedControl`。
- **状态**：提取失败（提示「本页无法进入阅读模式」）。

### 5.8 下载管理（09）

- **目的**：管理进行中与已完成的下载。
- **结构**：分段（进行中 / 已完成）→ 下载行（图标 + 文件名 + 大小/进度 + 操作：暂停/继续/打开/删除）。
- **组件**：`DownloadRow`、`ProgressRing`。
- **状态**：空（「还没有下载」+ 引导）、失败（红色状态 + 重试）。

### 5.9 书签与历史（10）

- **目的**：找回内容。
- **结构**：顶部分段切换（书签 / 历史）→ 搜索框 → 按文件夹分组（书签）或按日期分组（历史）→ 行（favicon + 标题 + 域名/时间 + 更多）。
- **组件**：`SegmentedControl`、`FolderHeader`、`BookmarkRow`。
- **状态**：空（引导）、批量选择。

### 5.10 无痕模式（11）

- **目的**：明确告知「不记录」。
- **结构**：全屏深黑（`--slate-950`）→ 遮罩图标 + 「无痕浏览」标题 + 说明三点（不记录历史 / 不留 Cookie / 不保存表单）→ 地址栏 + 底部工具栏（深黑变体，边缘加品牌描边以区分）。
- **组件**：`IncognitoBanner`、`IncognitoToolbar`。
- **状态**：正常。

### 5.11 设置（12）

- **目的**：集中配置。
- **结构**：分组列表（外观 / 隐私与安全 / 搜索 / 下载 / 无障碍 / 关于），每组一个标题 + 若干 `SettingRow`（标签 + 当前值 + 箭头或开关）。
- **组件**：`SettingGroup`、`SettingRow`、`Switch`。
- **状态**：正常。

## 8. 无障碍（Accessibility）

- 正文与次级文字对比 ≥ 4.5:1，大字号 ≥ 3:1（已在上表实测）。
- 所有可点目标 ≥ 48×48dp；相邻 ≥ 8dp。
- 图标按钮必须有可访问名称（如 `aria-label="关闭标签页"`），并暴露 `selected` / `expanded` 状态。
- 屏幕阅读器焦点顺序 = 视觉顺序；底部工具栏顺序：返回 → 前进 → 主页 → 标签 → 菜单。
- 支持系统字号放大至 200% 不破版；支持「移除动画」。
- 不以颜色为唯一指示（安全/警告同时有图标 + 文字）。
- 面板/抽屉打开时焦点被捕获，关闭后焦点回到触发按钮。
- 拖动/滑动类操作（边缘返回、标签排序）必须提供按钮等价物。

## 9. 实现注意事项（Jetpack Compose）

- 列表一律用 `LazyColumn` / `LazyVerticalGrid`，禁止 `Column + verticalScroll` 承载长列表。
- 每屏只保留**一个**滚动容器，避免嵌套滚动。
- `remember` 只存 UI 状态（滚动位置、动画）；业务状态放 ViewModel，列表用不可变集合（`PersistentList` / `ImmutableList`）。
- 主题用 `MaterialTheme` + 自定义 `CompositionLocal` 暴露语义 token，禁止在 Composable 内写死颜色。
- 地址栏 `TextField` 用 `KeyboardOptions(imeAction = Go)`，支持粘贴、密码管理器与自动填充。
- WebView 封装为独立 `BrowserView` Composable，生命周期与返回键由 `BackHandler` 统一接管。
- 边缘返回手势与 WebView 自身手势冲突需显式配置（`systemGestureExclusion`）。
