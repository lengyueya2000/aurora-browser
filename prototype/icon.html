为什么是极光

联网查了 Chrome / Edge / Firefox / Brave / Arc / 夸克 / UC 这一批的做法，再对着自适应图标的规范定的。

  • 品类里没有极光。浏览器图标几乎清一色蓝白地球或蓝白记号（Chrome、Edge、QQ、小米、Via、Alook、Samsung）。极光既是这个应用的名字，也是这个品类里的空位。
  • 形状在小尺寸下不散。细线在 1024px 上好看，缩到 48px 就没了——原来那个地球的线宽换算过来约 4dp，48px 下不到 2 个像素。现在主体是一条宽 13dp 的实心弧，最厚处在 48px 下约 6 个像素。
  • 做不对称，是为了不变成彩虹。第一版是一条对称的拱，缩到 64px 以下读起来就是一道彩虹。现在中心线左腿低而长、峰偏右、右腿收得快，端点收成一点。
  • 外面那层淡光是关键。彩虹是一条边缘锋利的色带，极光是一团散开的光。VectorDrawable 没有模糊，就用一层同轴、峰宽 26dp、透明度 13% 的带当晕；主体仍然清晰，所以大尺寸下轮廓不糊、小尺寸下不散。
  • 渐变是为了立住，不是为了花。Chrome 2022 版去掉阴影但加了很轻的渐变，就是为了小尺寸下不糊；这里青 → 薄荷 → 近白的三段渐变，让「一道光」在 32px 下仍然有明暗层次。
  • 一个主体 + 一个点缀。主弧 + 一颗四角星；晕和伴带都是同一个主体的层，不是另外的元素。规范里的经验是三个以上元素在小尺寸下会变成噪点。
  • 尺寸是算出来的。整块先按 108 画布画好，再等比缩到最远 32dp，落在安全区（半径 33dp）以内。圆形、圆角方形、方形遮罩都不会切到，系统做视差放大也不会。
  • 单色层单独画。主题图标按 alpha 取形状，所以单色层是同一套带子，只是纯白；伴带保留 40% 透明度，主题图标上也就有了亮淡两层。

落地位置

四个文件，都在 app/src/main/res/ 下。

  • drawable/ic_launcher_background.xml — 深青夜空（径向渐变）
  • drawable/ic_launcher_foreground.xml — 极光带 + 伴带 + 四角星
  • drawable/ic_launcher_monochrome.xml — 主题图标的单色层
  • mipmap-anydpi-v26/ic_launcher.xml — 把三层接起来
深链：#icon=aurora|globe|spark|diamond；键 1–4 同效。 几何由 .tmp/icon/gen_final.py 生成，和 ic_launcher_foreground.xml 同一套坐标。
