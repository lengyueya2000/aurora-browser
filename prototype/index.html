Compose 的惰性布局只组合与布局当前可见的条目，因此即使数据量很大也能保持流畅。使用 LazyColumn 承载纵向长列表，用 LazyVerticalGrid 承载网格。

// 只组合可见条目
LazyColumn(
  contentPadding = PaddingValues(16.dp),
  verticalArrangement = Arrangement.spacedBy(8.dp)
) {
  items(tabs, key = { it.id }) { tab ->
    TabRow(tab)
  }
}

避免嵌套滚动

同一屏内应只保留一个滚动容器。嵌套滚动不仅会带来手势冲突，还会让测量与布局在每一帧重复发生。

把业务状态放在 ViewModel，把滚动位置、动画等纯 UI 状态交给 remember，并始终使用不可变集合以避免静默的组合失效。

位置：右上角小窗 / 投屏（都是「把画面交出去」），右侧中间下载（单独一列，不与中间的播放键抢位置），右下角一排倍速 · 画质 · 适应 · 退出全屏（拇指自然落点），底部进度条占满宽度。小窗宽高比先夹到系统允许的 1/2.39–2.39——竖屏短剧的比例会越界，越界时系统直接抛异常，真机上表现为「点了没反应」；小窗里控制层与手势整层让开，否则会盖住系统的展开/关闭按钮。
清晰度面板列出 master.m3u8 里的各档（1080P / 720P / 480P），选「自动」交回播放器按网速自己切。同一清晰度有多条轨道（avc1 与 hevc）时只留码率最高的那条——否则面板上会出现一排「1080P」。
手势：左半屏上下滑调亮度、右半屏调音量、横向拖看进度（拖动中只预览，抬手才跳）、双击左右半屏进退 10 秒、单击显隐控制层。播放进度与倍速都会记住，下次接着看——看得不足 5 秒或离结尾不足 30 秒不记。
